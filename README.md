# Internal Communication Platform — Week 3

## Test Planning and Case Development

**Internship Project:** Junior Systems Analyst  
**Date:** 7 September 2026  
**Version:** 2.0

### Purpose
This repository contains the complete Week 3 System Testing and Quality Assurance submission for the Internal Communication Platform. It converts the approved Week 1 requirements and Week 2 design proposal into an executable test strategy.

### Repository Contents
- `Internal_Communication_Platform_Week3_Test_Plan.docx` — editable submission report
- `Internal_Communication_Platform_Week3_Test_Plan.pdf` — PDF reference copy
- `REPORT_DESCRIPTION.md` — 200+ word internship portal description
- `TEST_CASES.md` — quick reference for 20 test cases
- `requirements_traceability.csv` — requirement-to-test mapping
- `test_execution_template.csv` — tester execution sheet
- `DEFECT_REPORT_TEMPLATE.md` — defect logging template
- `TEST_DATA_GUIDE.md` — test account and data guidance

### Coverage
The plan covers functional, integration, system, regression, usability, performance, security and user acceptance testing. Twenty numbered test cases include authentication, messaging, channels, announcements, search, notifications, file sharing, administration, authorization, sessions, validation, audit logging, concurrency, recovery and usability.

### Submission
For the internship portal, upload the **DOCX** report in the "Upload your report file" field, paste the repository URL in the GitHub Project URL field, and paste the contents of `REPORT_DESCRIPTION.md` in the report description field.
