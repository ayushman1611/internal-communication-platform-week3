# Test Data Guide

Use synthetic data only.

## Accounts
- `employee1@test.local` — standard employee
- `employee2@test.local` — standard employee
- `manager1@test.local` — manager
- `admin1@test.local` — administrator
- `inactive@test.local` — deactivated account

## Data
- Sample direct and channel messages
- Department and project channels
- Search keywords with unique values
- Targeted announcements
- Supported file types within configured limits
- Unsupported and oversized files
- Boundary-length text
- 100 synthetic concurrent-user identities for performance testing

Do not use real passwords, personal data, production files, or production credentials.
